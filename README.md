## 📌 $\color{#27ae60}{\text{Project Overview}}$

> $\color{#2ecc71}{\text{The integration of wireless management systems into agriculture and home gardening}}$  
> $\color{#2ecc71}{\text{has transformed traditional plant care into a data-driven and automated process.}}$

* $\color{#55efc4}{\text{Maintaining the delicate balance of temperature, humidity, and light is essential for plants,}}$  
  $\color{#55efc4}{\text{yet manual monitoring is often inconsistent.}}$
* $\color{#00b894}{\text{This project presents an Automated Environmental Monitoring system designed to bridge}}$  
  $\color{#00b894}{\text{the gap between real-time data collection and proactive plant protection.}}$

---

## 🛠 $\color{#1abc9c}{\text{Components Required}}$

| Component | Function / Role |
| :--- | :--- |
| $\color{#2ecc71}{\text{ESP32}}$ | Main IoT Microcontroller |
| $\color{#00b894}{\text{DHT11}}$ | Temperature and Humidity Sensor |
| $\color{#16a085}{\text{LDR}}$ | Ambient Light Intensity Detection |
| $\color{#27ae60}{\text{LCD 1602}}$ | Real-time Local Status Display |
| $\color{#55efc4}{\text{Servo Motor}}$ | Automated Shading Mechanism Control |
| $\color{#05c46b}{\text{Relay and Pump}}$ | Water Spraying and Irrigation Activation |
